# さんすうクエスト v9 仕様書

## ゲーム概要
足し算・引き算を使ったファンタジーRPG形式の算数ゲーム。タブレット横向きを主な利用環境とし、5つのステージを進んで魔王を倒す。

## 問題数とステージ
全45問。通常4ステージは各10問、最終ステージのみ5問。

- 1〜10問：はじまりの もり / Cybern.mp3
- 11〜20問：ふしぎな どうくつ / Cold Amber.mp3
- 21〜30問：まほうの とう / Crate Lockup Tango.mp3
- 31〜40問：まおうの しろ / Quantized Panic.mp3
- 41〜45問：まおうの へや / Geology.mp3

## ライフ
各ステージ開始時に3ライフ。誤答・時間切れで1ライフ減少。ライフ0で現在ステージの先頭へ戻り、3ライフへ回復する。次ステージ到達時にも3ライフへ回復する。

## 問題
- 1問60秒。
- 3択。
- 繰り上がり・繰り下がりなし。
- 前半は2項式、後半は3項式を含む。
- 数式のフォントサイズは問題内容によって変化させず、画面サイズ区分ごとの固定値を使用する。

## ステージ遷移
通常ステージを突破すると、STAGE CLEARエフェクトと同時に現在BGMを約1.2秒かけてフェードアウトする。その後、ワールドマップ移動、次ステージ背景表示を経て、次ステージBGMを先頭から再生する。

初回もタイトルから直接問題へは進まず、ワールドマップ→はじまりの森→背景表示→第1問の順で開始する。

## クリアとリザルト
45問目を突破するとクリア演出を表示し、その後自動でリザルト画面へ移る。

リザルトでは以下を表示する。
- 45 / 45 クリア
- 総ミス数
- 時間切れ回数
- ステージやり直し回数
- 間違えた問題の一覧（選択した答え、正解、時間切れの別を含む）

リザルト画面には以下の2ボタンを置く。
- 最初から遊ぶ
- タイトルにもどる

## 画面・デザイン
現行のイラスト、マップ、問題GUI、固定数式表示、キャラクター発光縁取り、フォント体系を維持する。「よこむきにすると あそびやすいよ！」の表示は使用しない。
