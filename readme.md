# さんすうクエスト v20 — モンスター／ボスシステム統合版

## この版について
今回までに確定・検証したモンスター／ボスシステムを現行ゲームへ統合した版です。
正式モンスター画像はまだ制作前のため、通常モンスターおよび新規ボスは仮シルエット表示です。既存のラスボス画像は従来素材を参照します。

## 全体進行
- 表面・裏面は完全に別のモンスタープールを使用します。
- 1ステージは通常モンスター10問＋ボス5問＝15問です。
- 全5ステージ、合計75問です。
- 3ライフ制です。
- 通常戦で3ミスした場合は現在ステージの通常戦先頭へ戻ります。
- ボス到達後に3ミスした場合は、通常10問をやり直さずボス1問目から再挑戦します。

## 通常モンスター
各世界35体、表裏合計70体を想定しています。
各ステージで7体ずつ新規解禁されます。
- ★1：2体
- ★2：2体
- ★3 RARE：1体
- ★4 SR：1体
- ★5 SSR：1体

前ステージまでに解禁されたモンスターも以降のステージで出現します。

### レアリティ抽選
- ★1：50%
- ★2：30%
- ★3 RARE：15%
- ★4 SR：4%
- ★5 SSR：1%

抽選は「レアリティ抽選 → そのレアリティの解禁済みモンスターから抽選」の二段階です。
図鑑未登録モンスターには同一レアリティ内で軽い優先補正があります。

## 通常モンスター出現演出
背景・主人公・GUIを先に表示し、その後モンスターだけを個別に出現させます。
出現演出中はタイマーを開始しません。
- ★1：白系の短い出現演出
- ★2：青白い光
- ★3：RARE表示を伴う強化演出
- ★4：SUPER RARE表示を伴う豪華演出
- ★5：SSR事前予告＋最上位演出

問題難易度とモンスターレアリティは連動しません。

## ボス
各ステージに1体配置し、1体につき5問です。
通常10問終了後、通常BGMをフェードアウトしてからBOSS予告・出現演出を行い、ボス専用BGMへ切り替えます。

### ボスBGM
- STAGE 1〜4：`boss.mp3`
- 表面ラスボス：`maoh.mp3`
- 裏面ラスボス：`duel.mp3`

※上記mp3は `assets` に配置して使用します。

## ボス5問目の特殊行動
問題提示前にボスカットインを行い、その後特殊行動を発動します。演出中はタイマーを開始しません。
- STAGE 1・2：黒い妨害オブジェクト2個を問題レイヤーより前面で移動
- STAGE 3・4：制限時間30秒
- STAGE 5：黒い妨害オブジェクト2個＋制限時間30秒

5問目を再挑戦する場合も、カットインとボス行動を再発動します。

## ボス問題
STAGE 1〜4のボス問題は次ステージ内容の先取りです。

### 表面ラスボス
- 3桁＋3桁：必ず繰り上がりを含む
- 3桁－3桁：必ず繰り下がりを含む

### 裏面ラスボス
次のいずれかです。
- 2桁×1桁＋3桁
- 3桁＋1桁×2桁

乗算を先に処理する複合問題です。

## ボス撃破
5問目正解時は、正解表示→主人公カットイン→攻撃演出→ボスの長い消滅演出→STAGE CLEAR表示→従来のマップ／次ステージ処理、という順序です。

## モンスター図鑑用セーブデータ
以下を `localStorage` に保存する構造を追加しています。
- 表面図鑑登録ID
- 裏面図鑑登録ID
- 各モンスター遭遇回数

図鑑登録は「撃破時」ではなく「初遭遇時」です。
カード表示など図鑑GUIの最終デザインは、正式モンスター画像制作後に実装します。

## 検証済み内容
- レアリティ抽選比率
- 表裏モンスタープール分離
- ステージごとの累積解禁
- 通常10問→ボス5問→次ステージ
- ボス3ミス時のボス1問目復帰
- ボス5問目の視界妨害／30秒制限
- 裏面ラスボス5問→75/75→リザルト
- 最終問題正解後の75/75 HUD更新
- モンスター出現前に問題が残らないこと
- ボス再挑戦時に前回の妨害状態が残らないこと
