# さんすうクエスト v10

## 追加実装
- 表面45問・5ステージの既存構造を維持。
- localStorageによるセーブを追加。
- ゴルド：1ステージクリアで5G。
- コレクション100種：コモン50／アンコモン30／レア20。
- ショップとコレクションをタイトルから利用可能。
- 表面初回クリアで「時空の鍵」を確定入手し、ウラ面を解放。
- 表タイトルに「ウラステージへ」を追加。押すと専用エフェクト後にウラ面タイトルへ移動。
- ウラ面：魔法少女／夜の東京／5ステージ45問。
- ウラ面問題：2桁加減、3項加減、3桁3項加減、1桁掛け算、2桁×1桁。
- 表裏で共通のライフ3・60秒・3択・ステージやり直し・リザルトを利用。
- 各ステージクリアでBGMフェードアウト→マップ→背景→次BGM。
